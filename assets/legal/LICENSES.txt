SriEdu — third-party notices
============================

This file lists the third-party components bundled *inside* the app package.
Flutter's own package licences are additionally available at runtime from
Settings › Open-source licences (Flutter's `showLicensePage`), which enumerates
every Dart package compiled into the build.

Both are *variable* fonts (axes: wdth, wght). The OFL permits bundling and
redistribution inside an application, including commercial applications,
provided the fonts are not sold on their own and any modified version is not
distributed under the reserved font names. These files are unmodified.

Note on other scripts: Latin text in the English UI is rendered with the
platform font (Roboto on Android). Flutter's own engine embeds no font, so no
additional licence is required for it.


2. Illustrations
----------------

All SVG illustrations in assets/illustrations/ (logo.svg, books.svg, quiz.svg,
study_streak.svg, empty_search.svg, empty_downloads.svg, empty_history.svg,
empty_planner.svg, celebrate.svg, shield_check.svg) were authored for this
project as original vector artwork and are covered by the same licence as the
application source code. No third-party illustration assets are bundled.


3. Generated sample content
---------------------------

assets/data/sample_textbook.pdf is generated by tools/make_sample_pdf.py from
text original to this project. It contains no third-party content.

assets/data/*.json (subjects, catalogue, official sources, sample questions)
contain metadata and questions original to this project. Titles of government
publications are factual references and are not reproduced copyrighted text.


4. Content linked (not bundled)
-------------------------------

Textbooks, past papers and marking schemes are *not* distributed with this app.
SriEdu stores only a URL to the publisher's own website and opens it in the
user's browser:

  * National Institute of Education          https://nie.lk
  * Department of Examinations               https://www.doenets.lk
  * Ministry of Education                    https://moe.gov.lk

Rights and attribution for that content remain with the respective publishers.
See docs/CONTENT_POLICY.md for how this is enforced in code.


5. Runtime packages (summary)
-----------------------------

Flutter and the Dart packages listed in pubspec.yaml are distributed under
their own licences (predominantly BSD-3-Clause, with Apache-2.0 for some
Google-authored plugins such as google_mobile_ads, and the Firebase SDKs under
the Firebase Terms of Service). The authoritative, complete list for a given
build is generated automatically by:

  Settings › Open-source licences   (Flutter's license registry)

Run that screen on a release build before submitting to the store and keep a
screenshot of it with your release evidence.
